# Climbing Analytics - PRD

## Context
볼더링 영상을 AI가 분석해서 홀드 감지, 포즈 트래킹, 경로 예측, 힘 분포, 퍼포먼스 스코어를 오버레이로 보여주는 PWA 웹앱. 인스타 릴스 레퍼런스에서 영감. 개인 프로젝트 (비용 0원, 로컬 실행).

## 목표
- 볼더링 영상 업로드 → AI 분석 → 오버레이 영상 + 대시보드 제공
- 최종적으로는 실시간 촬영 중 분석도 지원

## 아키텍처 결정사항
- **영상 처리: Python 백엔드 중심** — 프론트는 재생 + UI만 담당
- 영상 업로드 → FastAPI가 프레임별 분석 → 결과 JSON + 오버레이 영상 → 프론트 전달
- 개인용 로컬 실행이므로 서버 비용 없음

## 요구사항

### Must Have (Phase 1)
- **홀드 감지**: YOLOv8 학습 → ONNX, 공개 데이터셋 활용 (Roboflow)
- **포즈 트래킹**: MediaPipe Python으로 관절 위치 추적
- **경로 예측**: 규칙 기반 (거리/각도/리치 범위로 확률 계산)
- **영상 오버레이**: 바운딩 박스 + 스켈레톤 + 경로 선 + 확률%
- **대시보드 UI**: 영상 옆 메트릭 패널 (Route Color, Vertical Velocity, 스코어)
- **영상 입력**: 파일 업로드 (2분 이내, mp4/mov/webm)
- **PWA**: 모바일 중심 사용

### Phase 2
- **힘 분포 추정**: 포즈 관절 각도 + 무게중심으로 물리 기반 추정
- **퍼포먼스 스코어**:
  - Smoothness: 관절 움직임 가속도 변화율 (jerk)
  - Technique: 무게중심 이동 효율성 (직선 대비 실제 경로)
  - Stable: 정지 구간 관절 흔들림
  - Adhesion: 손/발 홀드 접촉 시간 비율
  - Live Score: 위 4개 가중 평균 (100점 만점)
- **URL 입력**: 유튜브/인스타 URL 지원

### Phase 3
- **ML 경로 예측**: 프로 클라이머 영상으로 학습 데이터 자동 수집 → 모델 학습
- Phase 1의 홀드 감지 + 포즈 트래킹으로 라벨 자동 생성

### Nice to Have
- 실시간 카메라 촬영 중 분석
- 루트 색상 자동 감지
- 분석 결과 저장/히스토리

## 화면/흐름
1. 웹앱 접속 (모바일 or 데스크탑)
2. 볼더링 영상 업로드 (2분 이내)
3. AI 분석 시작 (진행률 표시)
4. 결과 화면:
   - **왼쪽**: 오버레이 영상 (홀드 박스, 스켈레톤, 경로 선, 힘 분포)
   - **오른쪽/하단**: 대시보드 (메트릭 바, Live Score)
5. 영상 재생하면서 메트릭 실시간 변화 확인

## 엣지 케이스
- 여러 명 → 주 클라이머 1명만 트래킹
- 클라이머 프레임 아웃
- 홀드 색상 ≈ 벽 색상
- 저화질 영상
- 극단적 촬영 각도
- 영상 2분 초과 시 거부 + 안내
- 홀드/포즈 감지 실패 시 fallback UI
- 모바일 기기 성능 (백엔드 처리이므로 OK)

## 범위 밖
- 네이티브 앱 출시
- 소셜/공유 기능
- 리드 클라이밍 (볼더링만)
- 실시간 촬영 분석 (Phase 1에서는 녹화 후 분석만)

## 기술 스택
- **프론트**: Next.js + PWA + Canvas (재생/UI만)
- **백엔드**: Python FastAPI (영상 처리 + AI 추론)
- **포즈**: MediaPipe Python
- **홀드 감지**: YOLOv8 (Colab 학습 → 로컬 추론)
- **영상 처리**: OpenCV + FFmpeg
- **비용**: 전부 무료 (로컬 + 오픈소스)

## 검증 방법
1. 샘플 볼더링 영상으로 업로드 → 분석 → 오버레이 결과 확인
2. 홀드 감지 정확도 육안 확인
3. 포즈 스켈레톤이 클라이머를 잘 따라가는지 확인
4. 경로 예측 선이 합리적인 홀드를 가리키는지 확인
5. 모바일(PWA)에서 결과 화면 정상 표시 확인
