# Known Limitations

## 홀드 감지
- **YOLOv8 모델 한계**: 범용 모델(yolov8n-freeclimbs)이라 특정 클라이밍장의 큰 볼륨형 홀드, 특이한 형태의 홀드를 감지 못하는 경우 있음
- **해결 방향**: 해당 클라이밍장 영상으로 모델 파인튜닝 또는 유저가 직접 홀드 위치 보정하는 UI

## 색상 분류
- **조명/그림자 영향**: 같은 민트색 홀드가 blue/mint/green으로 다르게 분류될 수 있음
- **HSV 기반 한계**: 규칙 기반이라 미묘한 색차 구분 어려움
- **해결 방향**: K-means 클러스터링 또는 학습 기반 색상 분류

## 루트 감지
- **손 근처 오판**: 클라이머 손이 다른 색 홀드 근처에 있으면 루트 색상 오판 가능
- **첫 접촉 의존**: 영상 초반 손 위치 기준이라 시작 홀드가 안 보이면 틀릴 수 있음
- **해결 방향**: 유저가 루트 색상 직접 선택하는 옵션 추가

## 퍼포먼스 스코어
- **2fps 한계**: 프레임 간격이 커서 Smoothness(jerk) 계산 정밀도 낮음
- **Adhesion**: 홀드 감지가 부정확하면 접촉 판정도 부정확
- **해결 방향**: frame_rate 높이거나, 보간(interpolation) 적용

## 경로 예측
- **규칙 기반 한계**: 거리+방향만 보고 예측하라 실제 클라이밍 패턴 반영 못함
- **홀드 의존**: 감지 안 된 홀드는 예측 후보에서 빠짐
- **해결 방향**: Phase 3 ML 모델로 교체

## 힘 분포
- **센서 없이 추정**: 포즈 좌표 기반 물리 추정이라 실제 힘과 차이 있음
- **관절 각도 미반영**: 현재 COM-접촉점 거리만 사용, 토크 미계산
- **해결 방향**: 관절 각도 기반 토크 계산 추가
